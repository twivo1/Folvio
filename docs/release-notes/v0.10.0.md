First public release of **Folvio** — convert, edit and combine files in one desktop workspace, offline.

## Downloads

| System | File | How to install |
|---|---|---|
| Windows 10/11 x64 | `Folvio-Setup-0.10.0-Windows-x64.exe` | Run the installer (no administrator rights needed). SmartScreen may warn because the installer is not code-signed yet: *More info → Run anyway*. |
| Linux x86_64 (glibc 2.39+, e.g. Ubuntu 24.04+, Fedora 40+) | `Folvio-0.10.0-Linux-x86_64.AppImage` | `chmod +x Folvio-0.10.0-Linux-x86_64.AppImage && ./Folvio-0.10.0-Linux-x86_64.AppImage` |
| Ubuntu 24.04 / 26.04 | `Folvio-0.10.0-Ubuntu-amd64.deb` | `sudo apt install ./Folvio-0.10.0-Ubuntu-amd64.deb` |

Verify downloads with `SHA256SUMS.txt`.

## What's inside

- **Auto Change** — edit the text of existing PDFs in place; only the changed text objects are rewritten,
  saving is verified and atomic, with backups.
- **Convert** — documents, spreadsheets, presentations, images, audio and video; every output is checked.
- **Combine** — photos, screenshots and scans into one PDF: drag & drop and `Ctrl+V`, reordering,
  perspective correction with automatic page detection, crop, annotations (pen, highlighter, shapes, text).
- **OCR** — searchable text layer for scanned PDFs (Polish and English included).
- **Batch** conversion, **reflow editing** of DOCX/ODT/RTF/Markdown/HTML/TXT.
- **Native Linux version** (new) — AppImage and .deb; same features, engines from the distribution.
- **Install missing engines** (new) — Windows: one click installs FFmpeg, LibreOffice and Tesseract with
  `winget`; Linux: the right `apt`/`dnf` command.
- **Self-test** (new) — `--selftest` runs real operations of the installed program and reports the result.

## Fixed since the last internal build

- Saving an edited PDF failed ("Text … is missing after saving") when the document embedded a subset of a
  font under exactly the system font's name (typical for PDFs written by Qt on Linux): the fonts are now
  kept apart.
- Redo works with both `Ctrl+Y` and `Ctrl+Shift+Z` on every platform.
- Combine: *Next: Edit*, *Sort by name* and *Save project* are disabled when they cannot do anything.

## Verified before publishing

Built and tested by GitHub Actions: the full automated test suite on Windows and Linux (unit, integration
and GUI tests), the Windows installer installed, self-tested and uninstalled on a Windows runner, and the
AppImage and .deb self-tested in clean Ubuntu 24.04, Ubuntu 26.04 and Fedora 43 containers.

## Known limitations

See [README → Limitations](https://github.com/twivo1/Folvio#limitations). In short: Linux PDF → DOCX uses
LibreOffice (positioned text boxes instead of Word's flowing paragraphs); FFmpeg, LibreOffice and the
Tesseract engine are installed separately; the Windows installer is not code-signed.
