Bug-fix release: Combine page reordering, the Perspective tool, and a much simpler Linux installation.

## Downloads

| System | File | Install |
|---|---|---|
| Windows 10/11 x64 | `Folvio-Setup-Windows-x64.exe` (= `Folvio-Setup-0.10.1-Windows-x64.exe`) | Run the installer |
| Linux Mint 22.x, Ubuntu 24.04 / 26.04 | `folvio_amd64.deb` (= `Folvio-0.10.1-Ubuntu-amd64.deb`) | Open it with the package installer, or: `wget -O /tmp/folvio.deb https://github.com/twivo1/Folvio/releases/latest/download/folvio_amd64.deb && sudo apt install /tmp/folvio.deb ffmpeg tesseract-ocr libreoffice-writer libreoffice-calc libreoffice-impress` |
| Other Linux x86_64 (glibc 2.39+) | `Folvio-x86_64.AppImage` (= `Folvio-0.10.1-Linux-x86_64.AppImage`) | `chmod +x Folvio-x86_64.AppImage && ./Folvio-x86_64.AppImage` |

Checksums: `SHA256SUMS.txt`. Linux guide: [docs/INSTALL_LINUX.md](https://github.com/twivo1/Folvio/blob/main/docs/INSTALL_LINUX.md).

## Fixed

**Combine · Arrange — drag & drop reordering.** Dragging a thumbnail moved only the *picture* (the list
behaved like desktop icons): cards could overlap and the page order did not change. Now:
- dropping on the left/right half of a card inserts before/after it (top/bottom half in the page list of the
  Edit step); a line shows where the page will land; drop on empty space = end of the document;
- cards always snap into a regular grid and are renumbered immediately; resizing the window re-flows them;
- several selected pages move together and stay selected; the view scrolls while dragging near its edge;
- leaving the view or pressing Escape cancels without changes; a drop in place adds no undo step;
- every reorder is a single undo step; the exported PDF and saved `.folvio` projects use the new order;
  annotations stay with their pages.

**Combine · Perspective.**
- After *Straighten*, a click on the corrected preview could grab an invisible corner and move it; arrow keys
  did the same. Now the click brings back the photo with its four corners.
- Perspective and Crop now look different (own icons, a coloured mode label on the canvas) and the panel says:
  *Drag each corner to match the corners of your document, then click Straighten.*
- The four corners always moved independently; this is now covered by GUI tests with mouse, X/Y fields,
  keyboard, 200 % zoom and 150 %/200 % display scaling.

## Linux installation

- New README *Install on Linux Mint / Ubuntu* section: graphical steps, one-line `apt` command, AppImage,
  system requirements, conversion engines, troubleshooting; detailed guide in `docs/INSTALL_LINUX.md`.
- Fixed-name downloads (`folvio_amd64.deb`, `Folvio-x86_64.AppImage`, `Folvio-Setup-Windows-x64.exe`) so the
  `releases/latest/download/…` links always give the newest version.
- Tested on Linux Mint 22.2 and 22.1 (official Mint containers), Ubuntu 24.04/26.04 and Fedora 43.
  **Linux Mint 21.x / Ubuntu 22.04 are not supported** (glibc 2.35; `apt` refuses the package, nothing is
  installed).
- The AppImage needs FUSE 3 (installed by default on Mint 22 / Ubuntu 24.04), not `libfuse2`.

## Notes

FFmpeg, LibreOffice and Tesseract are still installed separately (licences); PDF editing and Combine work
without them. Windows installer: not code-signed yet.
